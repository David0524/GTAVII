# AUDIO_SOURCES: provenance of every sound

**Rule (from the brief):** no real recorded music, no commercial sample libraries, no ripped game or
film audio, no imitation of real voices, stations, jingles or advertisers. Only our own synthesis,
our own procedural content, or CC0/public-domain recordings, each with a row here.

**Status (2026-11-26): every sound in the game is synthesised by code in this repository, and the
speech is rendered offline with eSpeak NG.** No third-party recording, sample, impulse response or
voice model is used anywhere. There is nothing to attribute and no licence other than the project's own.

principles; no specific product's recording or sound signature is copied.

## Source decisions (user, 2026-11-26: "use free methods for now; generate speech locally")
- **Music:** procedural period-style instrumentals, generated in the browser (`worklets/music.ts`).
- **Voice:** eSpeak NG, rendered offline at build time (`npm run audio:voices`, needs the `espeak-ng`
  package). Chosen over neural TTS because its voices contain no recording of a real person and carry
  no dataset-licence questions; it sounds robotic, which is the cost. Lines without a render (new or
  edited text) fall back to the formant placeholder until re-rendered.
Any recorded file added later gets a row in the table above before it is committed.

## Build-time tools and how their GPL-3.0 licences are handled (user approval, 2026-11-26)
The user approved, in the audio chat: "(a) add @echogarden/espeak-ng-emscripten@0.3.5 and
ffmpeg-static@5.3.0 as devDependencies, build-time only, never shipped".

| Tool | Version | Licence | Where it runs | Shipped to players? |
|---|---|---|---|---|
| `@echogarden/espeak-ng-emscripten` (eSpeak NG compiled with Emscripten; source: github.com/echogarden-project/espeak-ng, fork of espeak-ng/espeak-ng) | 0.3.5 (exact pin) | GPL-3.0 (`COPYING` in the package) | `tools/audio/voices.ts` only, in Node at build time | **No.** No file under `src/` imports it; Vite never bundles it. |
| `ffmpeg-static` (static ffmpeg binary) | 5.3.0 (exact pin) | GPL-3.0-or-later | `tools/audio/voices.ts` and `tools/audio/bake.ts`, as a separate process | **No.** |

What ships is only their **output**: the rendered speech files (`.webm`/`.m4a`). Output of a GPL program
is not covered by the GPL, so the game's own licence is unaffected. Anything that would put eSpeak code
into the browser bundle (in-browser synthesis) would ship GPL code and needs a separate decision.
Check: `grep -r "espeak-ng-emscripten\|ffmpeg-static" src/` must stay empty.
