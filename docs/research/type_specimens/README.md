# Type specimens: three directions for the user to pick

`type_A.jpg` (Transit Authority), `type_B.jpg` (Madison Avenue '74), `type_C.jpg` (Tabloid), and the title wordmark
(`wordmark.svg`, rendered in `wordmark.png`). The write-up is in `../TYPE_DIRECTIONS.md`.

**Images:** all reference crops are public-domain DOCUMERICA (NARA) photos. The NYCTA manual crop from the chat
version was swapped for a public-domain photo of Bell "phone" plates set in Helvetica.

**Title and HUD backgrounds:** the title panel sits over an untextured engine frame, and the HUD panel over a
1973 DOCUMERICA street photo standing in for the game.

**Regenerating:** `tools/ui/typeSpecimens.py` and `tools/ui/wordmark.py`.
