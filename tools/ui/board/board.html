Design A, every screen

The user picked map direction A and asked for the whole UI to match: a late-2020s game UI that stays immersive to 1970s New York, and nothing that looks AI-made. Design language: docs/DESIGN_A.md. Desktop 1600×900 and phone landscape 844×390 @2x, from the lab rig.

The rules every screen is checked against
No rounded-card dashboards, default sans voice, gradient blobs, glassmorphism, icons in identical circles, evenly spaced everything, beige on beige. Yes one hero per screen, deliberate asymmetry, real density and specific 1974 copy, square corners and hairlines, one amber accent, Libre Franklin voice with Heros Cn labels, our own icon drawings, period paper only where it's an object.
